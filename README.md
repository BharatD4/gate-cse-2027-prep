## 📱 Mobile App (PWA) Installation Guide

Tumhare phone par ye bina kisi APK ya Play Store ke direct install ho jaata hai aur **offline** bhi kaam karta hai:

### 🤖 Android Users (Chrome / Brave / Edge)
1. Browser me open karo: [https://bharatd4.github.io/gate-cse-2027-prep/](https://bharatd4.github.io/gate-cse-2027-prep/)
2. Bottom me aane wale banner **"📲 Install GATE Prep App"** par click karo.
   *(Ya browser ke 3-dots menu par tap karke **"Install app"** / **"Add to Home screen"** select karo).*
3. Home screen par **GATE Prep** app icon ban jayega. Tap karke full-screen native experience me use karo!

### 🍏 iPhone / iPad Users (Safari)
1. Safari browser me open karo: [https://bharatd4.github.io/gate-cse-2027-prep/](https://bharatd4.github.io/gate-cse-2027-prep/)
2. Bottom me **Share button** (square with upward arrow) tap karo.
3. Scroll karke **"Add to Home Screen"** dabao aur **Add** confirm karo.
4. App tumhari home screen par add ho jayega.

## ⚡ Key Features (Tumhe 3 Mahine me Qualify Karwane ke Liye)

1. **⏱️ Exam Countdown & Daily Mission Card**:
   - Real-time countdown timer GATE CSE (Feb 2027) ke liye.
   - Aaj ka fixed 4-hour daily target automatically screen par show hota hai.

2. **🧮 45+ Marks Qualifying Simulator**:
   - Live interactive score sliders.
   - Dekho kaise Aptitude (12M) + Discrete Math (6M) + C/DS (7M) + TOC (6M) + OS (6M) + DBMS (5M) se **42-44 Marks** ban jaate hain jo General Cutoff (~25-28) se **+16 marks aage** hai!

3. **📅 90-Day Step-by-Step Sprint Roadmap**:
   - **Phase 1 (Days 1-30):** High-ROI Foundations (C Pointers, Recursion, Trees, Aptitude, Discrete Math, OS Scheduling/Paging).
   - **Phase 2 (Days 31-60):** Core CS Scoring (TOC Minimal DFA/Decidability, DBMS Normalization/Serializability, Algorithms Master Theorem/Sorting, CN Subnetting, COA Cache).
   - **Phase 3 (Days 61-90):** PYQ Marathon (2014-2024), 5 Full Mock Tests, and Formula Revision.
   - Har single day ke liye curated free YouTube video playlist link aur GateOverflow PYQ goal.

4. **🎯 3-Tier Priority Matrix (The 80/20 Rule)**:
   - **Tier 1 (Do-or-Die - 45 Marks):** Aptitude, Discrete Math, C/DS, TOC, OS, DBMS (100% master karo).
   - **Tier 2 (Scoring Selectives - 25 Marks):** Algorithms, Linear Algebra/Probability, Digital Logic.
   - **Tier 3 (Cherry-Pick - 15 Marks):** CN (sirf Subnetting/Sliding Window), COA (sirf Pipelining/Cache). Baaki time-sink topics skip!

5. **📚 Formula Vault & Master Tables**:
   - TOC Decidability Master Table (Membership, Emptiness, Equivalence).
   - Closure Properties Master Table (Regular, DCFL, CFL, CSL, Recursive, RE).
   - OS EMAT, CPU Scheduling, Semaphore, Banker's formulas.
   - Sorting Algorithm Complexity & Stability comparison table.
   - 1-Click Copy Formula feature.

6. **📝 Authentic GATE CSE PYQ & Mock Simulator**:
   - Real GATE questions (MCQ, MSQ, NAT) with actual negative marking (-0.33, -0.66).
   - Official step-by-step solutions + **Trap Alert** (exam me hone wali silly mistakes).
   - 1-Click **"Add to Mistake Notebook"** button.

7. **🛡️ Personal Mistake Notebook (Error Log & Revision Vault)**:
   - Mistakes categorize karo: *Calculation Error*, *Conceptual Gap*, *Misread Question*, ya *Formula Forgot*.
   - Exam se pehle revise karke negative marks ko 0 karo.

8. **🍅 Integrated Pomodoro Focus Timer**:
   - 25m / 50m Deep Work sessions + 5m break.
   - Web Audio synthesizer chime sound aur session tracking.

9. **💾 Zero Data Loss & Offline-Ready**:
   - Saara progress browser `localStorage` me save hota hai.
   - Service Worker ke through offline access available hai.
   - JSON Backup file download ya restore karne ki facility.

## 💻 Local Machine par Run Kaise Karein

Agar bina internet ke apne computer par chalana ho:

### Method 1: Direct Double Click
`index.html` file par double click karo (Chrome/Edge me instant open ho jayegi).

### Method 2: Python Local Server
```bash

git clone https://github.com/BharatD4/gate-cse-2027-prep.git

# Navigate into the folder
cd gate-cse-2027-prep

# Start local server
python server.py
# (Automatically opens http://localhost:3000 in your browser)
```
